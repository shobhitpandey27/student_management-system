# Project Statement

## Project Title

**Student Management System – A Python-Based Academic Record Management System**

## Problem Statement

Educational institutions manage large amounts of student information such as personal details, academic marks, attendance, and performance records. Managing this information manually can lead to duplication, difficulty in searching records, calculation errors, and loss of information.

This project provides a simple Python-based Student Management System that allows users to create, read, update, and delete student records while also managing marks, attendance, reports, and class statistics.

## Scope of the Project

The project covers:

- Student record management
- Academic marks management
- Attendance management
- Automated percentage and grade calculation
- Student report generation
- Class-level statistics
- JSON-based persistent storage
- Input validation
- Basic automated testing

The current version is a console-based application intended for small educational environments and academic demonstration.

## Target Users

- Teachers
- Academic coordinators
- Lab instructors
- Small educational institutes
- Students learning Python

## High-Level Features

- Add new students
- View all student records
- Search by student ID
- Update student information
- Delete student records
- Enter or update marks
- Calculate percentage and grades
- Store attendance
- Generate individual reports
- Generate class statistics
- Save data permanently in JSON
